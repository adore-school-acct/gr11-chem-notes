# Scientific Notation

## Purpose

- Represent very large (1200000000000000000000000000000000)
- …or very small (0.00000000000000000000000000000069) numbers

## Structure

$\text{Decimal Number between 1-10} \times 10^{exponent}$

e.g. $5.79\times10^{-5}$

## Re-write in Scientific Notation

1. Find # between 1-10; move decimal between first non-zero digit and the proceeding digit
    
    e.g. 1,345,000,000,000 —> 1.345
    
    e.g. 0.000000681 —> 6.81
    
2. Count how many times you would have to move the decimal from original pos. to get scientific notation
    
    e.g. 1,345,000,000,000 —> 1.345000000000 moved 12x left
    
    e.g. 0.000000681 —> 00000006.81 moved 7x right
    
3. Exp. is the decimal movement; exp. is negative if decimal moved right
    
    e.g. 1,345… would be $1.345\times10^{12}$
    
    e.g. …681 would be $6.81\times10^{-7}$
    

## Standard notation

Do the above but in reverse

Move decimal place exponent number of times to the left if positive (+) or right if negative (-)

Or use calculator

## Arithmetic w/ Scientific Notation

- Multiplication & Division
    - multiply the “coefficient” of the notation
    - multiply the powers of 10
    - shift the decimal and adjust exponent (+ if shifted L and - if R) if necessary
- Addition & Subtraction
    - make sure both powers of 10 have same exponent
    - if not, shift decimal L/R and adjust exponent (same rule as above)
    - add the “coefficient” of the values; the power of 10 stays the same
    - shift the decimal and adjust exponent (+ if shifted L and - if R) if necessary
